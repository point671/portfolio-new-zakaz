# Промт для генерации верстки с Pixso MCP

## Использование:

1. Откройте Pixso и выберите нужный элемент/секцию
2. Скопируйте промт ниже и вставьте в чат
3. Укажите какой блок нужно сверстать

---

## Основной промт:

```
Сгенерируй адаптивную верстку для выбранного элемента из макета Pixso.

## Требования к коду:

### HTML:
- Семантическая разметка (section, article, nav, header, footer и т.д.)
- Методология именования классов: BEM (блок__элемент--модификатор)
- Атрибуты alt для изображений на русском языке
- Пути к изображениям в формате: @img/[папка]/[название].webp

### SCSS:
- Использовать миксин adaptiveValue для адаптивных значений:
  @include adaptiveValue(свойство, maxValue, minValue);

- Использовать функции:
  - rem(px) — для перевода px в rem
  - em(px) — для медиа-запросов

- Брейкпоинты:
  - $tablet: em(991.98) — планшеты
  - $mobile: em(767.98) — мобильные
  - $mobileSmall: em(479.98) — маленькие экраны

- Цвета и повторяющиеся значения выносить в SCSS-переменные в начале файла

### Адаптивность:
- Desktop-first подход
- Плавная адаптация через clamp() (миксин adaptiveValue)
- Медиа-запросы для критических изменений layout

### Структура SCSS:
\`\`\`scss
// Переменные секции
$section-bg: #значение;
$section-text: #значение;

.section-name {
    // Основные стили

    &__container {
        // Контейнер
    }

    &__element {
        // Стили элемента

        @media (max-width: $tablet) {
            // Адаптив для планшетов
        }

        @media (max-width: $mobile) {
            // Адаптив для мобильных
        }
    }
}
\`\`\`

## Формат ответа:
1. Сначала полный HTML-код блока
2. Затем полный SCSS-код со всеми адаптивными стилями
3. Краткие комментарии к сложным решениям (при необходимости)

Проанализируй макет и сгенерируй код.
```

---

## Дополнительные модификаторы:

### Для карточек:

```
Карточки должны быть в CSS Grid с gap: 20px, 4 колонки на desktop, 2 на tablet, 1 на mobile
```

### Для кнопок с градиентной рамкой:

```
Кнопки с градиентной рамкой:
border: 1px solid transparent;
background: linear-gradient(#цвет, #цвет) padding-box,
            linear-gradient(to bottom, #цвет1, #цвет2) border-box;
```

### Для форм:

```
Инпуты с плейсхолдером, border-radius: 30px, высота 60px
```

### Для таблиц:

```
Таблица на desktop через CSS Grid, на mobile - карточки с data-label атрибутами
```
